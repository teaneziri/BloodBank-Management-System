# Blood Bank Management System

## Project Description
This project is a **database system for managing a blood bank**, designed to organize and track donors, patients, blood donations, medical staff, and collection centers. It allows:

- Registration of donors and patients (public and private hospitals)
- Management of blood donations and related tests
- Tracking staff, receptionists, and volunteers
- Generating reports and statistics for collection centers
- Handling billing for private patients

**Implemented entirely in SQL**, this project demonstrates **relational database design, table creation, relationships, and queries**. An **ER Diagram** is included to visualize table structures and relationships.

---

## Technologies
- **SQL** – database
- **ER Diagram** – visual representation of tables and relationships
